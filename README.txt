AI BALANCE — ДЕМО-ПРОЕКТ

ЗАПУСК
1. Распакуйте архив целиком в одну папку.
2. Откройте index.html в современном браузере (Chrome, Edge, Firefox или Safari).
3. Для входа используйте любую корректную почту и код 12345.

ФАЙЛЫ
- index.html — структура приложения.
- styles.css — оформление и CSS-анимация жонглёра.
- app.js — вход, каталог задач, анализ, сохранение и экспорт.
- assets/ai_balance_app_icon.png — иконка приложения.

ВАЖНО
Это локальный демонстрационный прототип. Вход по коду проверяется в браузере и не является защищённой авторизацией. Данные анализа живут в памяти текущей вкладки; серверной базы и подключённой языковой модели пока нет. Каталог формирует шаблоны запросов для копирования в выбранный ИИ-сервис.
